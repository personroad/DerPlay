- 原有 297 项 Python 回归保留，新增 10 项针对 R192 的 UI 源码断言，共 307 项，实际全部通过。首次专项运行发现英文“启动/停止”两键缺失，补齐后全量通过。专项源码断言不是实际 UIKit 渲染测试。

- R191 → R192 仅四个 App 界面/文案文件变化：`App/DerPlayGlassUI.swift`、`App/ReceiverViewController.swift`、`App/SettingsUI.swift`、`App/Localization/Localizable.xcstrings`。音频处理、CarPlay、AirPlay、CarLife、仪表底层代码及认证识别模块、GitHub Actions 保持不变。未修改正式版本和 Build。

## 部署

使用总包中的 R192 all-in-one，Windows 双击 deploy.cmd；macOS/Linux 可用 bash deploy.sh。独立分支 `build/0.0.1-build18-r192`，GitHub Actions `Build DerPlay unsigned IPA`，runner `macos-15`。不推 main、不上传 private 历史、不绕过回归门禁。尚未上传 GitHub，也未生成 IPA。

## 真机验收重点

请确认安装的是 R192 分支实际生成的 IPA（所有候选均保持 Build18，系统版本号本身不能区分 R191/R192）。按以下顺序验收：主页浅色/深色预览阴影；通用设置全栈无右上按钮；连接模式和子页仅单层启动/停止按钮；启动后各需锁定设置锁定、停止后当前页解锁；画中画菜单两个状态顺序及选中勾；主页证书快捷入口及检测/清除弹窗；关于中的日志/设备/证书；原有协议和音频行为。任何仍出现的实际问题应保留截图及日志，不根据离线测试判断其已消失。
