# R132 Wi-Fi 密码异步读取
基于 SHA256 验证通过的 R131，修改 ReceiverViewController：启动、预设选择和 SSID 输入结束后的密码读取提交至既有串行凭据队列；主线程凭请求 UUID 和 SSID 提交结果，手动修改密码、开放网络状态或 SSID 时使旧请求失效。读取中阻止依赖密码的启动、连接、删除与切换；独立添加页保存可使旧读取失效并继续串行提交。仅刷新当前 Wi-Fi 页面且避免在字段编辑时重建。更新运行时文件摘要及原有方法哈希检查的精确允许项。新增四项静态源码回归检查。
实际测试：230 项 Python 测试通过，Swift 语法解析及 Preflight 通过。未进行 iOS SDK 类型检查、Xcode 编译、IPA 或真机验证。读取尚未完成时退出普通表单可能跳过自动保存，启动和切换需再次操作；串行队列暂无超时处理，原有切换及启动同步保存仍待处理。正式版本保持 Build18。
