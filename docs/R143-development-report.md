# R143 — 恢复互联模式次级选择页面

基线 R142，正式版本 0.0.1 Build18。根据用户真机反馈，撤销互联模式的悬浮弹窗，顶部「当前互联模式」恢复标准设置导航行。点击进入同一设置导航栈的原生列表页；沿用原有协议、图标、排列、勾选、未开放项及运行中/等待网络/Wi-Fi 保存期间保护。选择后执行原有设置回调，自动返回上一级设置页，不关闭整个设置窗口。保留 R142 通用、夜间模式、导航按钮修复及其他设置。未修改底层协议。

验证：R142 SHA256 验证通过；259 项 Python 回归通过（替换已撤销的弹窗专项测试），首轮因次级页额外 12pt 间距触发旧保护测试失败，移除额外间距后全通过；修改的 Swift 文件 frontend parse、Preflight 通过。当前环境无 Xcode，未执行 iOS 类型检查、IPA、远程推送或真机验收。

部署分支 build/0.0.1-build18-r143。
